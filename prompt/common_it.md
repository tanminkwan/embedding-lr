[요청]
내 역할(role)에서 실제로 나올 법한 "질의 + LLM 응답" 세트를 만들어줘.
QWEN 3.x 30B 수준의 챗봇이 답한다고 가정해.

[난이도 분포]
- 50%: 단순 커맨드 조회, 개념 상식 수준 (2~4줄로 끝나는 것)
- 50%: 실무 트러블슈팅 (원인 후보 여러 개, 확인 순서, 설정값 포함)
- 같은 주제 반복 금지, 각 기술 스택별로 골고루 분산할 것

[응답 스타일]
- 반말 (실무 동료가 알려주는 톤)
- 매우 간결하게. 서론·인사말·마무리 멘트 없이 본론만
- 명령어는 코드블록, 설명은 짧은 불릿
- 원인이 여러 개면 "확인 순서"로 번호 매겨서
- 가능하면 실무자가 놓치기 쉬운 포인트 한 줄 추가
- 장황한 설명, 일반론, "상황에 따라 다릅니다" 식 회피 금지

[출력 형식]
JSONL 포맷 (한 줄 = JSON 객체 1건, 키: 질의, 응답, 카테고리)
* 해당 데이터는 모두 'IT' 분류에 해당하므로, 카테고리는 모두 'IT'로 기재할 것.
* 응답에 코드블록/줄바꿈이 있어도 JSON 문자열 이스케이프(\n)로 표현되므로 그대로 담을 것 — 별도 이스케이프 규칙을 신경 쓸 필요 없음(json 표준 직렬화 사용).
